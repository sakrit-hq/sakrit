# Example: send_email with LangGraph

The 30-second demo (Act II, step 8): a LangGraph agent with a `send_email` tool
and a human-approval step. Crash it mid-run and it sends the email **twice**.
Add three lines of Sakrit and it sends **once**.

This single asset is simultaneously our clearest marketing, our integration
test, and our proof to ourselves that the core works.
